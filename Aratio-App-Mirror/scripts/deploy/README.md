# Deployment Scripts

This directory contains scripts for deploying the Aratio system to the remote server.

## Main Scripts

- `subir-a-hostinger.ps1`: Primary script for general deployment.
- `subir_core.ps1`: Deploys only core components.
- `subir_portal_lider.ps1`: Deploys the Portal Leader module.

For a full list of deployment tools, see [docs/UTILITIES.md](../../docs/UTILITIES.md).
