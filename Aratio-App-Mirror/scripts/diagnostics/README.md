# Diagnostic Tools

This directory contains tools for troubleshooting and verifying the system configuration.

## Key Tools

- `verificar_entorno_local.php`: Comprehensive local environment check.
- `diag_portal.php`: Portal-specific diagnostic interface.
- `diag_sess.php`: Session configuration validator.

For a full list of diagnostic tools, see [docs/UTILITIES.md](../../docs/UTILITIES.md).
