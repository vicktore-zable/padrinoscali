# Maintenance Scripts

This directory contains actions that perform cleanup or modify the system state.

## Core Actions

- `run_fix_views.php`: Ensures all required database views exist.
- `reset_opcache.php`: Clears server-side caches.
- `clear_cache.php`: Local cache management.

For a full list of maintenance tools, see [docs/UTILITIES.md](../../docs/UTILITIES.md).
