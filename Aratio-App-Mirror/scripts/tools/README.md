# General Tools & Data

Utility scripts for reporting, data exploration, and system inspection.

## Highlighted Tools

- `read_error_log.php`: Quickly view the last PHP errors.
- `list_fields.php`: Database schema field inspector.
- `summarize_hierarchies.php`: Relationship reporting tool.

For a full list of utility tools, see [docs/UTILITIES.md](../../docs/UTILITIES.md).
