## 1. BUG CRÍTICO — Red Jerárquica no cargaba en producción

### Síntoma
Al navegar a:
```
https://edisongiraldo.com/aratio/?page=colaboradores_red&root_doc=16832362
```
Aparecía: **"Seleccione una campaña para ver la red jerárquica"**

### Causa raíz — `index.php` línea 86

`index.php` calculaba `$campanaActivaId` usando la primera campaña del usuario
como fallback, pero **nunca escribía ese valor de vuelta a `$_SESSION`**:

```php
// ANTES (bug) — $campanaActivaId era variable local, no se persistía
$campanaActivaId = $_SESSION['campana_activa'] ?? ($campanas[0]['id'] ?? null);

// El dashboard funcionaba porque usa $campanaActiva (variable PHP)
// La red fallaba porque usa $_SESSION['campana_activa'] (sesión = NULL)
```

### Fix aplicado — `index.php`

```php
// DESPUÉS — se persiste en sesión si se usó el fallback
$campanaActivaId = $_SESSION['campana_activa'] ?? ($campanas[0]['id'] ?? null);

if ($campanaActivaId && empty($_SESSION['campana_activa'])) {
    $_SESSION['campana_activa'] = $campanaActivaId; // ← fix
}
```

### Defensa adicional — `pages/colaboradores_red.php`

Se añadió un mecanismo de recuperación vía `root_doc`. Si la sesión llega
vacía (p.ej. URL directa compartida), el sistema consulta la BD para
identificar la campaña del colaborador y restaura la sesión:

```php
if (!$campanaId && isset($_GET['root_doc'])) {
    $db = getDB();
    $stmt = $db->prepare("
        SELECT c.campana_id, cam.nombre as campana_nombre 
        FROM colaboradores c 
        JOIN campanas cam ON c.campana_id = cam.id 
        WHERE c.documento = ? LIMIT 1
    ");
    $stmt->execute([$_GET['root_doc']]);
    $result = $stmt->fetch();
    if ($result) {
        $campanaId = $result['campana_id'];
        $_SESSION['campana_activa'] = $campanaId;
        $_SESSION['campana_nombre'] = $result['campana_nombre'];
    }
}
```

## 2. BUG — Constante `ROOT_PATH` indefinida

### Síntoma
```
Uncaught Error: Undefined constant "ROOT_PATH" 
in pages/dashboard.php:268
```

### Causa
Al crear el módulo de Instagram se usó `ROOT_PATH` por error.
Esta constante **no existe** en el sistema.

### Fix
En `config.php` la constante correcta es `BASE_PATH` (definida en línea 113):

```php
// INCORRECTO
$jsonPath = ROOT_PATH . '/storage/instagram_data.json';

// CORRECTO
$jsonPath = BASE_PATH . '/storage/instagram_data.json';
```

**Archivos corregidos:**
- `pages/dashboard.php` línea 265
- `pages/actividad_instagram.php` línea 2
