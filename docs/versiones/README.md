# Snapshots por Versión

Cada subdirectorio contiene una copia de la documentación relevante en el momento del release.

## Convención

```
versiones/vX.Y.Z/
├── CHANGELOG.md          ← Changelog al momento del release
├── PLAN.md               ← Plan de la versión (si aplica)
└── docs/                 ← Snapshot de docs relevantes
```
